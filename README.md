# Сайт Ксении Маховой

Статический адаптивный сайт: HTML, CSS и JavaScript, без сборки и внешних JavaScript-зависимостей.

Запуск: `node server.cjs`, затем http://localhost:4173. Также можно открыть index.html напрямую.

Каталог редактируется в app.js, тексты — в index.html, оформление — в styles.css. Google Fonts необязательны: предусмотрены системные шрифты.

## Перед публикацией

- Согласовать тексты, образование, направления работы и актуальный состав каталога. Сейчас размещена подборка из 24 тем, а не полный каталог из 70 книг.
- Обложки созданы как графическое оформление каталога; это не изображения оригинальных PDF.
- Уточнить условия отдельного чата Telegram. Клуб ВК — 700 ₽ в месяц, каждая книга — 300 ₽; цены подтверждены владельцем. Вступление, покупка и продление идут через личные сообщения Telegram или ВК. Контактные кнопки открывают выбор мессенджера; карточки книг содержат оба варианта.
- Добавить платёжные ссылки Prodamus и настроить выдачу продуктов. Сейчас кнопки предлагают личный Telegram или ВК. Оплата и подписки на сайте не реализованы.
- На странице добавлены шесть обезличенных сокращённых цитат из скриншотов, предоставленных владельцем. Исходные скриншоты и медицинские схемы не размещены. Клинические случаи пока не добавлены.
- Подготовить необходимые реквизиты и документы для продажи и обработки данных с учётом фактической схемы работы.
- Проверить медицинскую корректность материалов до публикации. Названия книг не являются рекомендациями лечения.
